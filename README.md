CrochetCraft 

CrochetCraft is a beginner-level web application designed to showcase handmade crochet products through a simple and user-friendly interface.

Features:
Product showcase Simple and responsive user interface Basic navigation Beginner-level backend implementation Basic product data handling Technologies Used C# .NET HTML5 CSS3 JavaScript. 

Project Status: Work in Progress

CrochetCraft is currently a beginner-level project. The backend is partially implemented and is not yet complete. Some features may be limited or unavailable while development continues.

Getting Started:
Clone the repository. 
Open the project in Visual Studio. 
Restore the required dependencies. 
Build and run the application. 

About the Project: 
CrochetCraft was developed as a learning project to gain practical experience in web development, including front-end design and basic backend development using C# and .NET.
